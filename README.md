# کانفیگ‌یار (VPN Finder)

اپلیکیشن فارسی و راست‌به‌چپ برای فهرست‌کردن کانفیگ‌های عمومی OpenVPN و MS-SSTP با رابط Neo-Brutalism. نام سازنده در بخش دربارهٔ پروژه با عبارت دقیق **By AngelSolo** درج شده است.

## اجرا

```bash
npm install
npm run dev
```

سپس رابط را در `http://localhost:5173` باز کنید. برای build و اجرای production:

```bash
npm run build
set NODE_ENV=production
npm start
```

## ساختار

- `src/App.tsx`: رابط، جست‌وجو، فیلتر، مرتب‌سازی، refresh و حالت‌های loading/error/empty
- `src/parser.ts`: parser قابل توسعه برای JSON، متن ساده و خطوط OpenVPN/SSTP
- `server.js`: backend/proxy سبک برای رفع CORS و endpoint اختیاری سلامت
- `src/styles.css`: طراحی responsive و Neo-Brutalism بدون وابستگی CSS اضافی

منبع پیش‌فرض `http://150.40.105.10:46711/en/` است و از پنل تنظیمات قابل تغییر است. برای تنظیم محیطی می‌توانید `SOURCE_URL` و در صورت نیاز `HEALTH_URL` را تعیین کنید. پروکسی فقط درخواست HTTP(S) را می‌پذیرد و timeout دارد.

## محدودیت‌ها و ملاحظات

قالب منبع ممکن است ناشناخته یا تغییرپذیر باشد؛ در این حالت parser عمومی متن استفاده می‌شود و UI هشدار شفاف نشان می‌دهد. کانفیگ خام هنگام کپی یا دانلود بدون تغییر ارائه می‌شود. بررسی سلامت به endpoint امن و قابل تنظیم محدود است و برنامه هرگز به‌صورت خودکار به VPN وصل نمی‌شود یا محدودیتی را دور نمی‌زند.

برای ردیف‌های VPN Gate، لینک واقعی `do_openvpn.aspx` از همان ردیف استخراج می‌شود. پروکسی صفحهٔ جزئیات را واکشی می‌کند، لینک `openvpn_download.aspx` را از HTML واقعی پیدا می‌کند و همان فایل را با `Content-Disposition` و پسوند `.ovpn` تحویل می‌دهد؛ هیچ محتوای محلی یا ساختگی به‌عنوان کانفیگ دانلود نمی‌شود. MS-SSTP به راهنمای واقعی منبع لینک می‌شود و اگر منبع فایل قابل دانلود ارائه نکند، دکمهٔ دانلود جعلی نمایش داده نمی‌شود.

کانفیگ‌های شخص ثالث ممکن است مخرب، منقضی یا متعلق به فرد دیگری باشند. پیش از استفاده، منبع و محتوای آن‌ها را مستقل بررسی کنید و قوانین محلی، شرایط سرویس و ملاحظات امنیتی/حریم خصوصی را رعایت کنید. استفاده از این ابزار به‌معنای تأیید امنیت هیچ کانفیگ خاصی نیست.
